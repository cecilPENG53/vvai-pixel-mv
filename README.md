# vvai-pixel-mv

Claude Code skill：把一首歌（音频 + 带时间的歌词 srt/lrc）做成有故事的像素小人卡拍 MV（ClaudeMV 系列做法）。

顺序是：故事线 → 带画面的分镜表（可以反复改）→ 确认 → 用 HyperFrames 渲染 MP4。

- 怎么用：见 [SKILL.md](SKILL.md)
- 怎么装到新电脑：见 [INSTALL.md](INSTALL.md)
- 字体 `assets/fonts/` 是 Noto Serif SC / Noto Sans SC，SIL Open Font License 1.1，授权全文见 `assets/fonts/OFL.txt`。
