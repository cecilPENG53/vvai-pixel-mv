# 第 1 集用过的手法

第 1 集是 skill 之前手写的专属工程，逐帧逻辑写在那个工程自己的 `assets/mv.js` 里。下表记的是用过的手法。想复用模板里还没有的，就在新工程的 `assets/engine.js` 里照着写。

| 手法 | 出处（序幕手法库） | 第 1 集里怎么用 | 引擎 v2 里有没有 |
|---|---|---|---|
| 近景开场：积雪、发抖、抖雪、想事气泡、音波线 | — | 主歌开头：唱到季节和围巾的词时冒出围巾气泡 | 积雪、发抖有（`intro`）；回忆气泡有（`memory`）；音波线需要定制 |
| 每拍落地 + 水波 + 投影 + 呼吸 | L0019 | 全片 | 有 |
| 像素块斜向铺满再散开 | L0020 | 段落交界处换场 | 有（`pixel` 转场） |
| 受惊反应包：慢推 → 猛拉 + 速度线 + 问号 | L0021 + L0012 | 收到一条让人起疑的通知、看到陌生会话 | 有（`react` 事件） |
| 界面隐喻：输入框打字、退格重打、正在思考读秒 | — | 副歌 | 打字有（`type`）；退格重打、读秒需要定制 |
| “你看到的画面”卡片 + 红圈 | — | 主角怕对方误会的那句 | 需要定制 |
| 字在人后：巨字压在小人身后 | L0008 | 夜景牵手 | 有（`behind`） |
| 一句拆成三段，三连重拍三种版式 | L0013 | 拆成三段唱的那句 | 拆两半有（`split`）；三连需要定制 |
| 横甩转场 | — | 夜景 → 下一段 | 有（`whip`） |
| `/clear` 清屏接立体标题 | — | 结尾 | 标题有；`/clear` 需要定制 |

引擎 v2 已有的名字和参数见 [互动目录](interactions.md)。
