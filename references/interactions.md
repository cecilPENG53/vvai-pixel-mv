# 互动目录

`MV check` 只认这里列出的名字。要加新的动作或效果，先在本工程的 `assets/engine.js` 里写；确认好用、和用户商量后，再并进模板和本表。

| id | 动作 | 用在 |
|---|---|---|

| `window` | 趴窗 | 卧室、车窗 |
| `phone` | 看手机 | 等消息 |
| `type` | 打字 | 桌面、聊天、通话记录 |

## 歌词怎么出现

写在顶层 `lines` 里，键是句号：`"12": { "mode": "band", "enter": "spot", "exit": "smash" }`。

**显示方式 mode**

| mode | 效果 | 额外参数 |
|---|---|---|
| `band` | 底部大字条（默认） | `y`、`size` |
| `type` | 打进场景里的输入框（场景要有输入框：desk、phone、calllog），没有输入框时退回 band | |
| `say` | 角色头上的对话气泡 | `who` |
| `memory` | 放在回忆气泡下面 | |
| `behind` | 超大字放在角色身后（字在人后） | `y` |
| `glass` | 写在窗口的玻璃上（半透明、微糊） | `win`（窗口 id）、`at`（窗口内场景坐标）、`size` |
| `split` | 一句拆成左右两半 | `pos` `[[x,y],[x,y]]`、`size` |

**进场 enter**（band、behind、split 有效）：`pop` 弹出（默认）· `bounce` 逐字从上方弹跳落下 · `spot` 追光先亮再出字 · `sparkle` 闪光出现 · `swipe` 从侧面划入 · `lift` 从下面缓缓升起

**退场 exit**：`smash` 放大糊掉（默认）· `shatter` 碎成像素块 · `drift` 飘走（`dir` 1 / -1）· `drip` 往下滴落 · `recede` 往远处退 · `wash` 被雨冲掉 · `scatter` 气泡散开 · `blown` 被吹散 · `dissolve` 像素消散

`out`：手动指定开始退场的时间（让歌词跟着剧情动作一起消失，例如伞落地、被吹散的那一刻）。

## 转场（段的 trans）

| trans | 效果 | 适合 |
|---|---|---|
| `pixel` | 像素块擦除，颜色取下一个场景分组的主色 | 默认，换场景 |
| `train` | 列车从画面里穿过，车过去场景就换了 | 站台、离开 |
| `whip` | 甩镜（横向运动模糊） | 节奏快的切换 |
| `zoom` | 镜头往一个点钻进去，从里面出来是新场景；配上一段的 `zoomAt` | 钻进手机、屏幕、回忆 |
| `iris` | 圆圈收拢到一个点再打开 | 一幕结束 |
| `flash` | 闪白 | 重拍上 |
| `cut` | 硬切 | 同场景换镜头 |

## 卡点事件（events）

| type | 效果 | 限制 |
|---|---|---|
| `drop` | 全屏冲击：闪白、抖动、故障条、RGB 分离 | 全屏闪白每秒不超过 3 次 |
| `react` | 受惊反应包：先慢推 2.2 秒，到点猛拉、速度线、问号，角色吓跳 | 全片最多 2 次，`who` 指定谁受惊 |
